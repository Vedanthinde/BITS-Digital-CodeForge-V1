Marks file format guidance

The uploaded Excel file should contain exactly three required columns: BITS ID, Course, and Total Marks.

Total Marks must be a whole number from 0–100. Fractional values are rejected rather than silently changed.

Students receiving NC because they did not appear for the examination should not be included.
